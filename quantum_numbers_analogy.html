Think of the electron's location like a postal address in a city

🏢

n — which floor of the building

Principal quantum number → energy level

Imagine a tall building (the atom). Each floor is an energy level. Floor 1 is ground floor — lowest energy, closest to the nucleus. Floor 2 is higher up. Floor 3 even higher. The electron lives on one of these floors.

Real world

Higher floor = higher up in the building = farther from ground

In the atom

Higher n = more energy = electron lives farther from nucleus

n = 1 n = 2 n = 3 n = 4 ...
🚪

l — which type of room on that floor

Azimuthal quantum number → orbital shape

On each floor there are different room types — a studio (round), a 1-bedroom (dumbbell), a 2-bedroom (clover). Each room type has a different shape. The electron lives in one type of room on its floor.

Real world

Studio = round shape. 1-bed = elongated. 2-bed = branching layout

In the atom

l=0 (s) = sphere. l=1 (p) = dumbbell. l=2 (d) = clover shape

l=0 → s (sphere) l=1 → p (dumbbell) l=2 → d (clover)

Rule: l can only go from 0 up to n−1. Floor 1 only has studios. Floor 2 has studios + 1-beds. Floor 3 has all three types.

🧭

m — which direction the room faces

Magnetic quantum number → orientation in space

Same room type, but the window faces different directions — north, south, or east. A 1-bedroom facing north vs south is the same shape but oriented differently. Same for orbitals — a p orbital can point along x, y, or z axis.

Real world

Same room, window faces North / East / South — 3 orientations

In the atom

p orbital points along x-axis, y-axis, or z-axis (m = −1, 0, +1)

m = −l ... 0 ... +l s: only m=0 p: m=−1,0,+1 d: m=−2,−1,0,+1,+2

Put it all together — the electron's full address:

n=2Lives on the 2nd floor (second energy level)
l=1In a 1-bedroom room (dumbbell / p orbital shape)
m=0Window facing up/down (orbital points along z-axis)

→ This is the 2p₀ orbital — exactly one of your 6 plots!
